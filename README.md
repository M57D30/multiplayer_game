# Design Patterns in Multiplayer Game (C#)

Academic team project demonstrating the practical application of **software design patterns** in a simple multiplayer game built with C#.

- **Server**: C# console/server application handling networking, game state, and logic.
- **Client**: Windows Forms desktop client for player interaction.

**Note**: This was an early learning project focused on architecture rather than game polish or modern UI/UX.

## Purpose

The main goal was to apply common design patterns (e.g., Singleton, Factory, Observer, Strategy, State, Command) in a networked environment with multiple clients connecting to a central server.

## Tech Stack

- C# (.NET)
- Windows Forms (Client)
- TCP Sockets / Custom networking protocol (Server)
- Design Patterns

## Project Structure
multiplayer_game/
├── csharp-server/     # Server logic, game rooms, pattern implementations
└── windowsForms-client/ # WinForms UI, client networking

Each team member worked on separate branches to showcase individual contributions to the design and implementation.
